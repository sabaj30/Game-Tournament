#  🎮  Game Tournament Application

A backend application built with ASP.NET Core for managing game tournaments, players, teams, wallets, and authentication.

## Technologies

- C#
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication

## Current Features

- User registration and login
- Password hashing and verification
- JWT access token generation and validation
- Player and Admin roles
- Custom Result pattern for handling expected application errors
- Structured error codes for validation, conflict, not found, and server errors
- Exception handling for unexpected application failures

## Project Status

This project is currently under development.

Planned features include:

- Role-based authorization
- Protected endpoints
- Email verification
- Refresh tokens
- Tournament management
- Team management
- Wallet management
